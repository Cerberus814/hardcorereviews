A very unique gem of a run & gun game!! Raimodula.

📅 Jul 26, 2026👤 BY CERBERUS814
Pixelart 2D 2D Platformer Run and Gun
👍
RECOMMENDED 0.8 hrs on record

Raimodula is a fast run and gun shooter with a very unique pixel art style. The colors and pixelart visuals stand out a lot, giving the game a strong identity that feels different from most indie titles. A fantastic run and gun to play both alone or with a friend!

Raimodula Screenshot.by Cerberus814

Gameplay is simple but solid. You move, shoot, dodge, and react fast. There are two characters with different styles: one is faster and more agile, the other hits harder but feels slower. There are upgrades and different weapons. This adds some variety and replay value.

Raimodula Screenshot.by Cerberus814

The game can get quite challenging, especially in some platforming sections and boss fights. It’s not a long or complex game, but it’s fun, direct, and works well. If you like classic arcade shooters, this is an easy recommendation.
